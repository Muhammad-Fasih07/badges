# LeetCode Practice Hub

A beginner-friendly place to practice algorithm problems and share solutions.

Use the example solutions to learn. Then pick an **open** problem and add your own solution so other people can study it too.

## How to contribute

Anyone can help. You do not need to solve every problem.

1. Fork this repository
2. Pick a problem from the list below
3. Add your solution in a language folder, for example `python/solution.py`
4. Open a pull request

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the full rules and folder layout.

Want to add a new problem? Copy [templates/PROBLEM.md](templates/PROBLEM.md) and create a folder like `problems/0021-merge-two-sorted-lists/`.

## Good first contributions

These are open and beginner-friendly:

- [Palindrome Number](problems/0009-palindrome-number)
- [Valid Anagram](problems/0242-valid-anagram)
- [Binary Search](problems/0704-binary-search)
- [Merge Two Sorted Lists](problems/0021-merge-two-sorted-lists)

You can also add another language to a problem that already has one solution, such as Java or C++ for [Two Sum](problems/0001-two-sum).

## Folder layout

```text
problems/
  0001-two-sum/
    README.md
    python/solution.py
    javascript/solution.js
  0009-palindrome-number/
    README.md
```

Each problem folder has the statement, examples, and a hint. Solutions live in a language folder beside that README.
